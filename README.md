## MÔ TẢ BÀI TẬP
Ứng dụng quản lý danh mục vật tư/linh kiện sử dụng ListView dạng bảng chi tiết.

**Tính năng:**
- Thêm vật tư mới với validate (không để trống, không trùng mã, giá > 0)
- Cập nhật thông tin vật tư đang chọn
- Xóa dòng (có xác nhận Yes/No) hoặc xóa toàn bộ
- Click vào dòng trong ListView → tự nạp ngược dữ liệu lên form
